## 计划和资源占位

`provisionPlan` 要求明确操作 UUID、稳定 siteId、数字站点 ID、中央账户/数据库/origin、租户/负责人、目标分组/Worker/tag/当前 deployment、现有 manifest 摘要和目标 schema 版本/摘要。没有默认网站或默认账户；未识别字段、密钥字段、错误时区、非法目标和生产开关被拒绝。

数据库名称由 siteId 和完整操作 UUID 确定；管理域名固定为 `cms-site-<siteId>.beginos.org`。初始生产关闭、读副本关闭，创建位置提示为 WNAM。位置提示不是实际落点证明；后续资源适配器仍须核验 Cloudflare 返回值。

只读 `preview` 返回新操作或原操作进度，不写入占位，也不证明 Cloudflare 配额、资源归属或远程部署仍然符合预期。`reserve` 在同一 SQL 内重新检查中央站点/注册表冲突、负责人/租户存在和每组 50 站上限，保存固定计划及 SHA-256 摘要。唯一约束防止操作 ID 改换计划、重复分配 siteId/数字 ID/数据库名称/分组 binding；分组部分唯一索引使同一分组同时只有一个未完成建站操作。

计划只记录明确选择的负责人；不会因此签发登录凭据或授予站点权限。此模块仅供受限维护执行器调用，没有 HTTP/MCP 挂载，不保存账户 API Token，并拒绝在站点请求上下文内运行。

## 执行与恢复

六步依次是创建数据库、初始化 schema、种入站点资料、部署分组、验收和激活。每步先写入固定请求摘要，再调用外部能力；验证实际结果后提交结构化回执。回执和 checkpoint 由同一条语句与触发器原子提交。

数据库、schema、站点/租户/负责人等回执必须匹配计划；验收 deployment 必须等于部署步骤记录。最终完成还要求中央注册表已经 active、路由版本匹配、数据库/分组/binding/schema/域名/时区/操作 ID 均吻合、生产关闭且负责人有经理授权。日志不会自行伪造这些外部结果或注册表记录。

中央 D1 原子领取最多四个并行执行租约；每个租约 180 秒，执行器需每 30 秒调用心跳。领取推进 epoch；过期租约无法续期或提交新回执，旧执行器释放也不会影响新执行器。释放执行租约不释放资源占位或分组保护。

如果某步开始后没有回执，结果视为不明。默认恢复拒绝领取；显式对账模式可以领取，但 `begin` 返回 `reconcile`，不是 `new`。后续适配器必须检查既有 Cloudflare 资源/部署/数据库状态后决定记录结果，不能仅凭此日志重复发送创建请求。日志能约束本库状态，无法回滚或为外部 API 提供跨系统事务、服务端 fencing 或绝不重复计费保证。

完成后的相同回执重试不重复推进版本；不同回执、意图或计划被拒绝。操作记录永久保留；取消未完成操作和释放其占位尚未提供接口，应恢复原操作或通过后续经过验证的人工处置流程处理。
