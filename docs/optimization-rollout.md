## 当前构建配置

非 main 分支的 Workers Builds 执行 `pnpm run ci:build`，部署命令只输出验证完成信息。
main 的生产构建必须使用 `pnpm run ci:build` 和 `pnpm run ci:deploy`，部署脚本检查当前提交对应的构建完成标记、账户和资源绑定。

`ci:build` 的测试使用独立的本地 D1/R2 模拟绑定（位于 Cloudflare 构建容器内），无生产队列绑定。
构建标记仅在全部检查和 OpenNext 打包成功后生成。构建成功本身不能证明业务功能正常，发布后仍需只读检查。
